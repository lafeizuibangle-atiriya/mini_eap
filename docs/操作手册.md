# Mini-EAP 操作手册（现场人员用）

## 1. 系统启动顺序

每天开工按顺序启动：**数据库 → 设备模拟器 → EAP 主控端 → Web 报表端**（命令见《部署手册》第 4 节）。

## 2. 主控端界面说明

| 区域 | 内容 |
|---|---|
| 顶部连接栏 | 设备地址、端口、连接/断开按钮 |
| 设备状态列表 | 机台号、状态、Recipe、进度%、腔温、腔压；状态着色：绿色=加工中，黄色=暂停，红色=报警 |
| 命令按钮区 | 加载 Recipe / START / PAUSE / STOP / 复位报警 / 确认选中报警 |
| 报警列表 | 时间、机台、代码、级别、内容、数值 |
| 消息日志 | 命令应答、连接事件、运行结束事件 |
| 底部状态栏 | 当前存储模式（MySQL / File 降级） |

## 3. 日常操作流程

### 3.1 正常加工一批

1. 状态栏确认"存储: MySQL"（File 模式也可用，仅不入库）；
2. 连接设备，确认两台机台状态为 IDLE；
3. 填机台号与 Recipe（ETCH01 用 ETCH_STD_01 / ETCH_HI_TEMP_02，DEP01 用 DEP_STD_01）；
4. 点"加载 Recipe"→ 日志出现 OK → 点"START"；
5. 观察进度到 100%，日志出现"运行结束 … -> OK"，即完成。

### 3.2 报警处理（重点）

1. 设备状态变红（ALARM），报警列表出现新行（如 E1024 腔温超上限）；
2. 选中该报警行，点"确认选中报警"——主控端自动发送 RESET；
3. 确认状态回 IDLE、报警行状态变"已复位"；
4. 在 Web 报表核对报警记录已入库。

### 3.3 暂停与中止

- PAUSE：加工中暂停，可再 START 继续；
- STOP：中止本次运行，结果记为 ABORT。

## 4. Web 报表使用

浏览器打开 `http://127.0.0.1:5050`：

- **报警记录**：近 100 条，含级别、数值、复位状态；
- **生产运行记录**：近 100 条，OK 绿色 / ABORT 红色；
- 也可直接调 API：`/api/runs`、`/api/alarms`、`/api/stats`。

## 5. 注意事项

1. 先启动模拟器再连主控端，顺序颠倒会连接失败；
2. 请勿同时打开两个模拟器实例占用同一端口；
3. 关机前先在主控端点"断开"，再依次关闭三个程序；
4. 演示前建议先执行 `database/03_seed.sql` 恢复演示数据。
