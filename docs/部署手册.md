# Mini-EAP 部署手册

## 1. 环境准备

1. 安装 .NET SDK 8.0+（下载 https://dotnet.microsoft.com/download/dotnet/8.0）
2. 安装 Python 3.8+ 并确认 `python --version` 可用
3. 安装 MySQL 5.7/8.0，确认服务已启动

## 2. 数据库初始化

在 MySQL 中依次执行（账号密码按现场实际调整）：

```sql
source D:/Code/mini_eap/database/01_init.sql;
source D:/Code/mini_eap/database/02_procedures.sql;
source D:/Code/mini_eap/database/03_seed.sql;
```

或命令行：

```bash
mysql -uroot -p123456 < database/01_init.sql
mysql -uroot -p123456 < database/02_procedures.sql
mysql -uroot -p123456 < database/03_seed.sql
```

验证：`USE mini_eap; SELECT * FROM equipment;` 应返回 2 台设备（ETCH01 / DEP01）。

## 3. 数据库连接配置

默认连接串：`Server=localhost;Port=3306;Database=mini_eap;Uid=root;Pwd=123456;`

如现场不同，启动前设置环境变量：

```bash
# Windows PowerShell
$env:MINIEAP_MYSQL = "Server=xxx;Port=3306;Database=mini_eap;Uid=xxx;Pwd=xxx;"
```

主控端与报表端共用该变量。**MySQL 未启动时系统不报错**，存储自动降级为本地 JSON 文件（`MiniEapHost/bin/.../logs/minieap_events.jsonl`）。

## 4. 启动服务（三个窗口按顺序）

```bash
# 窗口 1：设备模拟器（监听 9000）
python D:/Code/mini_eap/simulator/device_simulator.py --port 9000

# 窗口 2：EAP 主控端（WinForm 界面）
cd D:/Code/mini_eap && dotnet run --project MiniEapHost

# 窗口 3：Web 报表端（http://127.0.0.1:5050）
cd D:/Code/mini_eap && dotnet run --project WebReport --urls http://127.0.0.1:5050
```

## 5. 启动后验证清单

| 步骤 | 操作 | 预期结果 |
|---|---|---|
| 1 | 主控端填 127.0.0.1 / 9000 点"连接设备" | 日志显示已连接，设备列表出现 2 台机台 |
| 2 | 选中 ETCH01，点"加载 Recipe" → "START" | 状态变 PROCESSING，进度与腔温持续变化 |
| 3 | 等待运行完成或点"PAUSE"/"STOP" | 日志出现 run_done，MySQL run_history 新增记录 |
| 4 | 观察报警 | 腔温连续超限后状态变 ALARM（红色），alarm_history 新增 E1024 |
| 5 | 点"复位报警" | 状态回 IDLE，报警标记为已复位 |
| 6 | 浏览器打开 http://127.0.0.1:5050 | 报表页显示运行记录与报警记录 |

## 6. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 连接失败 | 模拟器未启动 / 端口不一致 | 确认窗口 1 已运行、端口一致 |
| 状态栏显示"存储: File" | MySQL 未启动或连接串不对 | 按第 3 节检查；不影响功能演示 |
| 报表页无数据 | 尚未产生事件 | 先在主控端跑一轮 START |
| dotnet run 报 SDK 版本 | 未装 .NET 8 | 安装 SDK 8.0+ 后重试 |
